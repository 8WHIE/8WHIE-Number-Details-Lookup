# 8WHIE Cyber Info API

A simple Flask API demo by **8WHIE — Worldwide Hackers Intelligence & Ethics**.

## Important
This project generates demo/random information. It does **not** actually track phone numbers, reveal a person's real-time location, or access telecom databases.

## Run
```bash
pip install -r requirements.txt
python app.py
```

Then use:
`/search?number=9876543210`
